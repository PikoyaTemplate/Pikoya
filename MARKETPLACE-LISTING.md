## Short Description
A polished, responsive HTML storefront template for digital-service businesses, online shops, and service marketplaces. Pikoya combines a warm vintage/editorial visual style with a complete front-end shopping flow — from browsing services to cart, checkout, accounts, orders, and a demo admin area.

## Full Description
Pikoya is a clean, responsive Digital Services Marketplace template built for creators, agencies, digital shops, and service businesses that want a complete storefront interface without a framework or complicated build process.

The design uses a warm editorial/vintage direction while keeping the interface practical, readable, and easy to customize.

### Features
- Responsive desktop and mobile storefront
- Editorial/vintage visual direction
- Homepage hero and service collection
- Subscription, Credits, Boosts, and Digital Goods service flows
- Plan selection and quantities
- Customer ID / username field
- Order notes
- Shopping cart with totals and item removal
- Demo checkout flow
- Order numbers and order statuses
- My Account
- My Orders
- Favorites
- Settings
- Support
- Help / Guide
- FAQ sections
- Demo admin order-management interface
- Local-storage cart, favorites, and demo orders
- Clean HTML, CSS, and JavaScript structure
- No framework or npm setup required
- Ready for static hosting

### Easy to Customize
Change service names, prices, plans, text, colors, typography, and business information directly in the source files.

No build tool is required. The template can be opened locally or deployed to GitHub Pages and other static hosts.

### Important
Pikoya is a front-end template and demonstration storefront. Real authentication, SMS/email verification, payment processing, databases, supplier/API fulfillment, persistent customer accounts, and secure admin functionality require a backend or third-party services.
